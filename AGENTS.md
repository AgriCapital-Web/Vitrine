# Presentation rules
- Use the shared global institutional layout and cinematic presentation styles for public pages so the menu, typography and responsive behavior stay consistent.
- News animations must preserve the complete article content and offer pause and manual photo navigation; reduced-motion preferences disable automatic playback.
- The client portal is an external service; this site presents its access section without changing the external application.
- PublicPageMotion progressively enhances public routes with shared scroll reveals; admin routes remain untouched and reduced-motion keeps content immediately readable.
- PublicPageHero provides photographic institutional page openings with manual animation pause, keeping public page framing consistent.
